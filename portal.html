버전 히스토리 & 릴리즈 노트 (Changelog)

v0.5.0 2026-11-11 전사 표준화 릴리즈: 브라우저 탭 및 화면 전역 고시인성 버전 뱃지 탑재
  • 화면 전역 고시인성 버전 배지 탑재: 상단 헤더, 사이드바 브랜드명 옆, 대시보드 메인 배너 및 브라우저 탭 타이틀에 v0.5.0 선명하게 상시 표시
  • 상업용 ISO/IATF 규격 생산일지: SMC-PRD-F01 Rev.03 A4 1장 풀핏 인쇄 완벽 지원
  • 클라우드 & 오프라인 동시 배포: Vercel CDN 실시간 자동 배포 및 단일 파일(SMC_system.html) 동기화
v0.4.2 2026-11-11 상업용 A4 단일 페이지 인쇄 서식(SMC-PRD-F01 Rev.03) 고도화 및 Vercel 자동 배포
  • 상업용 표준 서식 고도화: 문서번호 SMC-PRD-F01, Rev.03, 보존연한 및 3단 규격 결재란(작성/검토/승인) 탑재
  • A4 1장 100% 무손실 인쇄: 7번 출고 전 품질확인 5대 항목과 8번 특이사항 상자가 용지 하단 여백 안쪽에 넉넉하게 들어가도록 정밀 최적화
  • 원클릭 자동 Git Push & 배포: 변경사항 실시간 GitHub 푸시 및 Vercel 글로벌 CDN 즉시 반영
v0.4.1 2026-11-11 SMC 일일 생산일지 인쇄 양식 A4 1장 완벽 맞춤 (Single-Page Fit)
  • A4 1장 단일 인쇄 최적화: 인쇄 시 '7. 출고 전 최종 품질 확인'의 하단 2개 항목(이물질 혼입, 포장)이 2페이지로 잘려 넘어가는 문제 해결
  • 고밀도 인쇄 레이아웃: 롤 생산 표(1~12롤) 및 특이사항 상자 높이/마진을 최적화하여 1~8번 전 섹션이 A4 1장에 꼭 맞도록 개편
  • 단일 실행본 동기화: SMC_system.html 및 SMC_system_EN.html 최신 빌드 동시 배포
v0.4.0 2026-10-15 글로벌 영문(English) 완벽 지원 및 GitHub Pages CI/CD 자동 배포
  • 한국어 / 영어 원클릭 실시간 전환 지원 (전 메뉴, 대시보드, 9종 처방, 설정값 계산기, 배합지시서, 라벨 등)
  • GitHub 원격 저장소 연동 및 GitHub Actions 라이브 자동 배포 파이프라인 구축
v0.3.0 2026-10-15 현장 엑셀 4개 파일 전 시트 100% 무손실 통합
  • SMC 생산 공정 표준서(SMC-STD-001) 및 예방보전 가이드 수록 (한국어 / 베트남어 병기)
  • 수기 생산일지 사진 촬영 스마트 스캔(AI OCR 자동 인식) 탑재
  • 물탱크 배합 총 제조원가(원재료·부재료·노무비·경비) 계산서 및 9종 처방 수록

배포 방식별 운영 가이드

배포 채널 적합한 대상 및 장소 실행 및 접근 방법 네트워크 요구사항
단일 HTML 파일 배합실/성형라인 현장 PC, 태블릿, 외부 협력사 USB 복사 또는 사내 공유폴더에서 더블클릭 완전 오프라인 (인터넷 불필요)
▲ Vercel Cloud (초고속 CDN) 모바일, 현장 태블릿, 사무실, 글로벌 지사 (권장) Vercel 공식 웹 URL 접속 (링크) 인터넷 연결 필요 (Anycast 초저지연)
온라인 GitHub Pages 사무실, 연구소, 출장지, 모바일 스마트폰 공식 웹 URL 접속 (링크) 인터넷 연결 필요 (HTTPS)
사내 인트라넷 (NAS/IIS) 사내 폐쇄망 환경의 모든 전사 임직원 사내 웹서버에 파일 복사 후 사내 IP 접속 사내 로컬 네트워크(LAN)
